## 2. 里程碑
- **M1（可用骨架）**：阶段 1–3 完成 → 菜单能停靠/收缩、列表启动三个软件、打开设置面板。
- **M2（客户端闭环）**：阶段 4 + 7 完成 → 菜单能对未运行软件静默更新/修复，版本状态可见。
- **M3（服务端闭环）**：阶段 5–6 完成 → 总/分支服务器上线，客户端分支优先、回退总服务器。
- **M4（发布）**：阶段 8–9 完成 → 单文件分发、WebView2 自带、可部署到客户机房。

## 3. 依赖与外部事项
- 需在可联网的开发机安装 Go ≥1.21、Wails v2、Node（仅前端依赖时）、WebView2 fixed-version runtime 包。
- 总/分支服务器可先用同一台机器不同端口联调。
- 现有三个绿色包路径需录入 apps.json（见需求表 R47）。

## 4. 风险与对策
- WebView2 在老旧机房缺失 → 自带 fixed runtime（R02）。
- 客户机仅局域网隔离无法回源 → 改做分支 HA（R36）。
- 更新中点开软件 → 暂存+原子切换+进程复检（R21–R23）。
- 写权限不足 → 菜单置于用户可写位置（R43）。
