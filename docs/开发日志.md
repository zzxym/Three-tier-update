## 初始架构决策（2026-10-26 整理）
1. **客户端**：Go + Wails 单文件 exe；悬浮窗停靠左/右、点击收缩小圆、呼出菜单；可视化配置面板。
2. **启动引擎**：菜单按 apps.json 直接 `exec.Cmd` 启动，设子进程 env（便携数据重定向、DOTNET_ROOT 等）/workdir/args，无外部脚本。
3. **更新引擎**：后台仅对未运行软件静默更新；文件级 sha256 diff + 校验；分支优先、回退总服务器；暂存+原子切换+进程复检防冲突；只动 App\ 不碰 Data\；支持损坏修复。
4. **服务端**：总服务器提供 `/<tenant>/<appId>/manifest.json` + 文件服务 + 租户授权 + 清单生成工具；分支服务器为带租户授权的穿透缓存（缺啥回源并缓存）。
5. **版本**：本地包内 manifest.json 记录版本+文件哈希，作为权威版本与修复基线；更新成功后回写。
6. **安全**：哈希校验使篡改服务器无法投毒；配置落盘于用户可写位置；开机自启用启动文件夹快捷方式（不写注册表）。
