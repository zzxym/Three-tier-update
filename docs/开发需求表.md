# 软件管理菜单与对比更新服务 — 开发需求表

> 维护说明：本表为活文档。需求或功能变化时，直接在此追加/修改对应行，并在《开发日志》记录变更。
> 项目目录：`软件绿化\MenuClient\`
> 最后整理：2026-10-26

## 1. 项目背景
- 已完成三个绿色免安装包：班级优化大师（EasiCare 2.1.0.3825）、希沃白板5（EasiNote 5.2.4.11582）、希沃展台（EasiCamera 2.1.0.4419）。
- 目标：开发「软件管理菜单」（悬浮窗客户端）+「对比更新服务」（总服务器 / 分支服务器），实现内网环境下绿色软件的集中启动、版本比对、差异更新与损坏修复。
- 适用范围：客户局域网内部署，支持「公司总服务器 → 客户分支服务器 → 局域网设备」三级拓扑。
